# 정기 운영 체크리스트

## 결론

운영 체크는 “서버가 켜져 있는지”만 보는 것이 아니라, 판단 루프, 데이터 신선도, 히스토리 진실성, 알림, 백업, 실거래 잠금 상태를 함께 확인해야 합니다.

## 매일 장 시작 전

- [ ] 패널 접속 가능 여부 확인
- [ ] heartbeat 최신성 확인
- [ ] 오라클 패널 서비스 active 확인
- [ ] 뉴스/차트 freshness 확인
- [ ] 장 상태가 정규장인지 확인
- [ ] 실거래 잠금 상태 확인
- [ ] 전일 장마감 리포트 확인

## 장중

- [ ] 뉴스 refresh 지연 여부 확인
- [ ] 특정 종목 차트 누락 여부 확인
- [ ] AI 판단이 데이터 부족을 숨기지 않는지 확인
- [ ] 장중 평가는 미확정으로 표시되는지 확인
- [ ] 알림 채널 수신 상태 확인

## 장 마감 후

- [ ] 마감 확정 기록 생성 여부 확인
- [ ] 장중 평가와 마감 기록 분리 확인
- [ ] 후보 사후라벨 업데이트 확인
- [ ] 체결품질/매도품질 리포트 확인
- [ ] 실패 taxonomy 리포트 확인
- [ ] 감사 로그 백업 생성 확인

- [ ] 공개 저장소 민감정보 스캔

- [ ] 외부 백업 복원 가능성 확인
