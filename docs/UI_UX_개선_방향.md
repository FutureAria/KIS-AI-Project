# UI/UX 개선 방향

KIS AI 트레이더는 처음에 많은 정보를 한 화면에 보여주는 방식으로 시작했습니다.

하지만 사용자가 처음 봤을 때 정보량이 많으면 핵심을 놓칠 수 있기 때문에, 화면을 더 직관적으로 나누는 방향으로 개선했습니다.

## 개선 목표

- 처음 보는 사람도 현재 상태를 바로 이해할 수 있게 만들기
- 중요한 숫자와 판단을 크게 보여주기
- 세부 근거는 필요한 화면에서만 확인하게 하기
- 밝은 테마와 어두운 테마 모두에서 잘 보이게 하기
- 버튼, 카드, 상태 표시가 서로 구분되게 하기

## 상세형

상세형은 기존처럼 많은 정보를 확인하는 화면입니다.

주요 대상은 관리자나 프로젝트를 깊게 확인하려는 사용자입니다.

- 판단 근거
- 뉴스 상태
- 보유 비중
- 검증 기간
- 히스토리
- 운영 상태

## 간편형

간편형은 처음 보는 사람도 빠르게 이해할 수 있도록 핵심만 보여주는 화면입니다.

주요 대상은 일반 사용자나 발표를 보는 사람입니다.

- 오늘 상태
- 모의자산
- 총 손익
- AI 결론
- 다음 행동
- 최근 움직임

## 화면 설계에서 배운 점

기능이 많다고 좋은 화면이 되는 것은 아닙니다.

사용자에게 중요한 것은 “지금 무엇을 봐야 하는지”와 “왜 이런 상태인지”를 빠르게 이해하는 것입니다.
