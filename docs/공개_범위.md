# 공개 범위

이 저장소는 포트폴리오 설명용 공개 저장소입니다.

회사가 봤을 때 “이런 프로젝트를 만들었구나”를 이해할 수 있는 수준까지만 공개합니다.

## 공개하는 것

- 프로젝트 소개
- 만든 이유
- 주요 기능 설명
- 화면 구성 방향
- UI/UX 개선 방향
- AI 활용 방식
- 모의투자와 실거래 전환 원칙
- 아키텍처 요약
- API 명세 요약
- 트러블슈팅과 문제 해결 기록
- 면접 설명 정리
- 기술 면접 꼬리질문
- 공개용 포트폴리오 PDF
- 운영 안정화 설계
- 포트폴리오 공개 체크리스트

## 공개하지 않는 것

- 실제 서비스 코드
- 인증 정보
- 계좌 정보
- 서버 접속 정보
- 운영 명령
- 내부 로그
- 실거래 설정
- 원본 테스트 데이터
- 민감한 시스템 구성
- 현재 운영 중인 실제 도메인 링크
- 실제 통합 점검 결과 원본 JSON/로그
- 알림 채널, API 키, 서버 경로가 드러나는 운영 스크립트

## 사이트 링크 공개 기준

운영 중인 사이트 링크는 인증이 걸려 있어도 내부 API 경로, 운영 상태, 관리자 화면의 존재를 추측하게 만들 수 있습니다.

따라서 공개 README에는 실제 운영 링크를 직접 올리지 않고, 면접이나 검토 상황에서만 read-only 데모 또는 캡처 자료로 공유하는 것을 원칙으로 합니다.

## 공개 기준

공개할지 애매한 자료는 올리지 않습니다.

포트폴리오에서는 기능을 전부 보여주는 것보다, 어떤 문제를 어떤 방식으로 해결했는지를 설명하는 것이 더 중요합니다.

## 운영 점검 결과 공개 기준

운영 점검은 공개할 수 있지만, 원본 로그와 내부 명령은 공개하지 않습니다.

| 항목 | 공개 여부 | 이유 |
|---|---:|---|
| 점검 목적 | 공개 | 운영 역량 설명에 필요 |
| 점검 항목 목록 | 공개 | 안정성 설계 이해에 도움 |
| 실패/확인 필요/외부 데이터 필요 분류 방식 | 공개 | 거짓 없는 운영 원칙 설명 가능 |
| 원본 JSON/로그 | 비공개 | 서버 경로, 내부 상태, 토큰 흔적 포함 가능 |
| 실제 도메인/서버 접속 정보 | 비공개 | 운영 보안 위험 |
| 알림 webhook/API 키 설정 | 비공개 | 보안 위험 |
