# 공개 범위

이 저장소는 포트폴리오 설명용 공개 저장소입니다.

회사가 봤을 때 “이런 프로젝트를 만들었구나”를 이해할 수 있는 수준까지만 공개합니다.

## 공개하는 것

- 프로젝트 소개
- 만든 이유
- 주요 기능 설명
- 화면 구성 방향
- UI/UX 개선 방향
- AI 활용 방식
- 모의투자와 실거래 전환 원칙

## 공개하지 않는 것

- 실제 서비스 코드
- 인증 정보
- 계좌 정보
- 서버 접속 정보
- 운영 명령
- 내부 로그
- 실거래 설정
- 원본 테스트 데이터
- 민감한 시스템 구성

## 공개 기준

공개할지 애매한 자료는 올리지 않습니다.

포트폴리오에서는 기능을 전부 보여주는 것보다, 어떤 문제를 어떤 방식으로 해결했는지를 설명하는 것이 더 중요합니다.
