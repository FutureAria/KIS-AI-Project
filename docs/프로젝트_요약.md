# 프로젝트 요약

KIS AI 트레이더는 한국 주식 데이터를 기반으로 AI가 모의투자 판단을 보조하는 대시보드 프로젝트입니다.

이 프로젝트의 핵심은 자동으로 매수와 매도를 많이 하는 것이 아니라, AI가 왜 기다리고 왜 판단했는지를 사용자가 이해할 수 있게 보여주는 것입니다.

## 문제 정의

AI 투자 서비스는 판단 과정이 보이지 않으면 사용자가 결과를 믿기 어렵습니다.

특히 자동매매처럼 위험이 있는 서비스에서는 다음 내용이 명확해야 합니다.

- 지금은 모의투자인지 실거래 준비 단계인지
- AI가 왜 매수하지 않는지
- 어떤 조건이 부족한지
- 장이 열리지 않은 날에는 왜 대기하는지
- 검증이 끝난 뒤 바로 실거래로 넘어가지 않는 이유

## 해결 방향

이 프로젝트는 사용자가 AI 판단 흐름을 눈으로 확인할 수 있도록 화면을 구성했습니다.

- 요약 화면에서 현재 상태를 빠르게 확인
- 모의투자 화면에서 보유 종목과 최근 행동 확인
- AI 판단 화면에서 대기, 매수, 차단 이유 확인
- 히스토리 화면에서 누적 손익과 하루 변화를 분리 확인
- 운영 화면에서 시스템 상태와 데이터 수집 상태 확인

## 프로젝트 원칙

- 근거 없는 매수 금지
- 과도하게 보수적인 무행동 방지
- 모의투자 검증 우선
- 실거래 전환은 별도 승인 단계로 분리
- 민감 정보와 실제 운용 정보는 공개하지 않음
