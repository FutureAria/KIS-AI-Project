# AI 활용 정리

이 프로젝트에서는 AI를 단순한 코드 생성 도구가 아니라, 기획과 개발을 함께 도와주는 팀원처럼 사용했습니다.

## AI 사용 방식

AI는 역할을 나누어 사용했습니다.

- 기획 정리
- MVP 범위 설정
- UI/UX 개선 아이디어
- 프론트 화면 개선
- 백엔드 구조 점검
- 버그 원인 분석
- 문서 정리
- 발표 자료 구성

## AI 사용 규칙

AI가 마음대로 프로젝트 방향을 바꾸지 않도록 기준을 두었습니다.

- 확인되지 않은 내용은 사실처럼 말하지 않기
- 구현하지 않은 기능을 구현했다고 하지 않기
- 기존 기획을 바꿀 때는 이유를 설명하기
- 변경한 내용은 문서에 기록하기
- 민감 정보는 공개 자료에 넣지 않기

## KIS 프로젝트에서 적용한 예시

이 프로젝트에서는 다음 내용을 계속 문서화했습니다.

- 사용자가 요청한 UI 개선 사항
- AI가 기다리는 이유
- 모의투자와 실거래 전환 기준
- 데이터 수집 상태
- 밝은 테마와 어두운 테마에서 보이는 문제
- GitHub 공개 범위

## 공개 자료 원칙

GitHub에는 회사나 평가자가 프로젝트 방향을 이해할 수 있는 내용만 올립니다.

실제 코드, 인증 정보, 계좌 정보, 서버 접속 방법, 운영 로그, 내부 점검 기록은 공개하지 않습니다.
